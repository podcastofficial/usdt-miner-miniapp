2. **Points & Earning** — full ledger (status/idempotency/metadata), task catalogue + verification flow, daily reward rules
3. **Referral** — referral_code capture, required-channel verification (@USDTMinerUpdates, @USDTMinerPayments), bot webhook, 1,000 Points exactly once, anti-abuse
4. **Finance** — BEP-20 on-chain deposit verifier, withdrawal lifecycle (quote/fee/net, reserve, review, payout hash)
5. **Admin panel** — dashboard, user search, task/deposit/withdrawal/campaign queues, audit viewer
6. **Community** — leaderboard (paginated), Advertise, Official Channel, Payment Proof, How to Use, Games (coming soon)
7. **Premium UI + Launch** — Black + Orange 3D redesign, accessibility, test matrix, deployment guide, go-live checklist
