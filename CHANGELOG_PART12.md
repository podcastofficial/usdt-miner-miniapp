# Phase 2 / Part 5 — Safety, Admin & Growth (v1.12.0)
## What's new
- **Admin roles.** Super admin = the Telegram IDs in `ADMIN_TELEGRAM_IDS` (unchanged, cannot be edited in the app, so a leaked database can never create one). New limited roles in **Admin > Roles**: **support** (users, block / unblock, tasks, campaigns, task proofs, payment-proof visibility, fraud flags) and **finance** (withdrawals, deposits, ledger check, CSV export, analytics, audit, fraud flags). Settings, Points adjustment, broadcasts, promo, games, contests, roles and server tools are super-only. The server checks the permission on **every** admin call (`lib/roles.js`, `ACTION_PERMS`); an admin action with no entry is denied to everyone. The Admin tab only shows what the role may use. Role changes are audited (`role.set`, `role.remove`) and take effect within ~5 s.
- **Fraud flags** (**Admin > Safety**). Three rules: the **same wallet** on several accounts (withdrawal addresses and deposit sender addresses), a **referral burst** (N qualified referrals inside one window), **rapid claims** (N tasks inside one window). Auto-flag + human review: **Reviewed / Dismiss / Reopen** with a note, **Open user** jumps to the profile. A flag **never blocks, freezes, debits or rejects anything** (a test enforces it). Each finding has a unique key, so scanning twice never duplicates a flag. Scan now (always available) or the daily cron when **Automatic fraud scan** is ON (starts OFF). Thresholds are in Settings.
- **CSV export** (**Admin > Export**): users, withdrawals, deposits, ledger; newest 5,000 rows, days filter, copy or download, audited (`export.csv`). Cells that start with `= + - @` get a leading `'` so Excel / Sheets cannot run them; plain numbers (also negative Points) stay numbers; UTF-8 BOM so Hindi names open correctly.
- **Analytics** (**Admin > Analytics**): active users per day, new users per day, Points created / spent per day (14 days, in the daily time zone), active 24h / 7d / 30d, retention (back after 1 and 7 days), referral conversion (30 days). Charts are SVG with a text alternative and a numbers list.
- **Languages and theme** (**More > Settings**): English, Hindi, Hinglish (`public/i18n/*.json`, same keys in all three, English fallback) and a **light theme** (`public/light.css`, contrast-checked). Dark stays the default. The choice is saved on the device and in `users.user_lang`; new users start in Hindi if their Telegram language is Hindi.
- **Health alerts** to every admin on Telegram: API 5xx errors (at most one per action per 30 min), ledger mismatch and many open withdrawals (at most one per 6 h; level default 20), new fraud flags. Messages contain no secrets or user data (tokens, DB URLs and hex strings are scrubbed). **Admin > Home > Check + alert admins** tests it. Setting **Health alerts** (ON).
- **Deposit auto-credit hardening.** Turning **Auto-credit verified deposits** ON is refused until at least one real deposit has been verified AND approved by hand.
- **Settings** (group "Safety & Alerts"): `fraud_enabled` (**OFF**), `fraud_wallet_min_users` (2), `fraud_burst_count` (10), `fraud_burst_minutes` (30), `fraud_claims_count` (15), `fraud_claims_minutes` (10), `health_alerts` (ON), `alert_open_withdrawals` (20).
- **DB**: `011_safety_admin.sql`: `fraud_flags`, `admin_roles` (roles `support` / `finance` only), `users.user_lang`, two read indexes.
- **API**: `setLang`, `adminFraudList`, `adminFraudReview`, `adminFraudScan`, `adminRoles`, `adminRoleSet`, `adminRoleRemove`, `adminExport`, `adminAnalytics`, `adminHealth`, `adminHealthRun`. `bootstrap` adds `admin_role`, `admin_perms`, `user.lang`. The daily cron now also runs the fraud scan (if ON) and the health checks.
- **Tests**: new `tests/safety.test.js`: permission matrix, fraud rules, CSV escaping, i18n key coverage (+ runtime), analytics maths, alert throttling, auto-credit gate, light-theme contrast, wiring, migration.
