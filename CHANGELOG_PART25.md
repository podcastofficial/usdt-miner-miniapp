# Part 25 — Mining & Booster Insights

Adds user mining history/active booster status and an admin report for Auto-Miner plan sales, active machines, claimed Points, historical booster activity, and projected plan arithmetic. It does not modify Auto-Miner accrual, claim, booster purchase, or ledger payout logic. ROI is arithmetic only and is not a promise of token value or redemption.

API: `miningInsights`, `adminMiningReport`.
Migration: `023_part25_mining_reports.sql`.
